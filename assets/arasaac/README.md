# Pictogramas ARASAAC na prancha visual

Pictogramas de **Sergio Palao**, do [ARASAAC](https://arasaac.org/), de propriedade do **Governo de Aragão, Espanha**. As imagens PNG foram incorporadas sem alterações no desenho. A prancha visual reúne os pictogramas com rótulos e frases em português.

Os pictogramas e a prancha visual são disponibilizados sob [CC BY-NC-SA 4.0](https://creativecommons.org/licenses/by-nc-sa/4.0/deed.pt-br). O uso comercial exige autorização dos titulares, conforme os [termos de uso do ARASAAC](https://arasaac.org/terms-of-use).

## Busca de novos pictogramas

A criação de símbolos também permite consultar o catálogo público e guardar uma cópia PNG escolhida pelo responsável. Essas imagens não são adicionadas ao repositório: ficam nos dados locais do símbolo, com ID, origem, autoria e licença, e acompanham o backup protegido por arquivo. Aplicam-se as mesmas condições de uso e atribuição. Veja [ARASAAC_E_API_DE_SUGESTOES.md](../../ARASAAC_E_API_DE_SUGESTOES.md).
