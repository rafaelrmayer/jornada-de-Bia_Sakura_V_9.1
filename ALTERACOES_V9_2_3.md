# V9.2.3 — refinamento visual e preparação para PostgreSQL

- Paletas rosa, azul e verde com fundo pastel e cores de ação mais escuras.
- Controles com área mínima de 44px; rótulos móveis ampliados; foco visível; respeito a movimento reduzido.
- Manifesto atualizado sem sufixo antigo V.1; cache do service worker versionado.
- Documentação e exemplo de contrato para futuro backend separado, **sem conexão ou migração de dados**.
- Não foram alterados os arquivos JavaScript de lógica de comunicação, segurança ou IA.

**Atenção:** CSS antigo contém regras `!important` e vários temas; conferir visualmente cada tela e tema no navegador. Testes automáticos de sintaxe não substituem teste de acessibilidade com usuários e tecnologias assistivas.
